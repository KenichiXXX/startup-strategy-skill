## 决策摘要

先说“建议选什么、为什么现在、证据有什么限度”，再用小表展示：

| 选项 | 业务证据 | 现金与人员占用 | 成果和观察期 | 主要风险/停止条件 |
|---|---|---|---|---|

最后只列真正需要人决策的项：决定什么、谁决定、建议期限和不决定的影响。若无需用户决定就可以完成的内部工作，直接完成并报告结果。

## 岗位或合作专项附页

招聘：业务瓶颈 → 岗位成果 → 必要能力 → 合理实操与评价 → 接口和管理人 → 完整成本/未决项 → 到岗及里程碑。

合作：双方动机 → 真实增量 → 试点范围 → 双方负责人 → 资源与分配草案 → 验收 → 数据/权利/排他/退出未决项。

融资准备：可用资金与现金桥 → 要验证的里程碑 → 缺口与时间 → 资金用途 → 替代路径 → 可对外核实的证据；承诺和未到账款单列。
